### Summary

I compared Logistic Regression with two ensemble learning methods, Random Forest and XGBoost, using the Titanic dataset. Random Forest achieved similar performance to Logistic Regression, while XGBoost achieved slightly lower accuracy with the selected parameters. Feature importance analysis showed that Sex, Fare, Age, and passenger class were among the most influential variables.
